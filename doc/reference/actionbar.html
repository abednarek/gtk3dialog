actionbar widget

The GTK3-only GtkActionBar places contextual controls at the start, end or visual center of a horizontal bar. It does not change the meaning of the older hbuttonbox tag.

Definition 

<actionbar>
    <button actionbar-pack="start">...</button>
    <text actionbar-pack="center">...</text>
    <button actionbar-pack="end">...</button>
</actionbar>

Tag Attributes

Each direct child accepts actionbar-pack with start (the default), end or center. At most one child may use center. Invalid values fall back to start with a warning. Child order within each side is retained. The child keeps its own variable, actions, visibility and sensitivity.

Shared directives and conditions follow the common widget contract.

Value and Actions

The container has no independent value. Use child variables and actions for all interaction. Common show, hide, enable and disable actions apply to the whole action bar. Input, output, save and clear do not apply to it.

Example 

<window><vbox>
    <actionbar>
        <button actionbar-pack="start">
            <label>Back</label>
            <action>echo back</action>
        </button>
        <button actionbar-pack="end">
            <label>Apply</label>
            <action>echo apply</action>
        </button>
    </actionbar>
</vbox></window>
