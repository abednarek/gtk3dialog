headerbar widget

The GTK3-only GtkHeaderBar is an optional client-side titlebar for a window. It holds controls at the start and end plus an optional custom center widget. Existing <window> dialogs without this tag keep their native window-manager decorations.

Definition 

<window title="Example">
    <headerbar show-close-button="true">
        <button headerbar-pack="start">...</button>
        <button headerbar-pack="end">...</button>
    </headerbar>
    <vbox>...ordinary window body...</vbox>
</window>

The headerbar and body are separate direct children of <window> and may appear in either XML order. The window title is inherited when no headerbar title is supplied. The headerbar may have no child controls when only a title and subtitle are needed. The custom titlebar is installed before the window is shown.

Tag Attributes

NameDescriptionValuesSince
titleHeader title, overriding window titleText 0.9.1
subtitleSecondary title lineText 0.9.1
show-close-buttonShow standard window controlsBoolean 0.9.1
has-subtitleReserve room for a subtitleBoolean 0.9.1

Each direct child accepts headerbar-pack: start (default), end or center. Only one child may use center. A centered child is GTK3's custom title widget and replaces the built-in title/subtitle display. Invalid values fall back to start with a warning. Child variables, actions and sensitivity remain independent.

Shared visual attributes and conditions follow the common widget contract.

Value and Actions

The headerbar has no independent value. Use child variables and actions. Common show/hide/enable/disable actions affect the bar. Input, output, save and clear do not apply to it. A direct headerbar changes that window to client-side decoration, so its border and titlebar appearance may differ from other windows under the same window manager. It does not change other dialogs or the main GTK3 showcase gallery.

Example 

<window title="Documents">
    <headerbar subtitle="Choose a file" show-close-button="true">
        <button headerbar-pack="start">
            <label>Back</label>
            <action>echo back</action>
        </button>
        <button headerbar-pack="end">
            <label>Open</label>
            <action>echo open</action>
        </button>
    </headerbar>
    <vbox><text><label>Window body</label></text></vbox>
</window>
