fontchooserdialog widget

The GTK3-only GtkFontChooserDialog opens a native font chooser. It is a top-level program root and can be launched from another GTKDialog window.

Definition 

<fontchooserdialog title="Choose a font">
    <variable>FONT_DIALOG</variable>
    <default>Sans 8</default>
    <output file>selected-font.txt</output>
    <output file response="true">response.txt</output>
    <action signal="response">save:FONT_DIALOG</action>
    <action signal="response">closewindow:FONT_DIALOG</action>
</fontchooserdialog>

Value and Actions

The variable value and ordinary file output are GTK3 font descriptions, using the same format as fontselection. <default>, command or file <input>, and refresh set or reload the font. Generic writable chooser properties, including preview-text and show-preview-entry, may be set as XML attributes.

Plain <action> and signal="response" run synchronously when the dialog responds. A separate <output file response="true"> receives a name such as ok or cancel. An <input response="true"> may set an initial response or emit it on a later refresh. fileselect: is a file-path action and does not set a font. clear resets only the stored response; it does not clear the chosen font. The dialog supports closing and relaunching.

Shared directives and conditions follow the common widget contract.

This widget is available since GTKDialog GTK3 0.9.1.
