arrow widget

A decorative GTK3 GtkArrow. It draws one of four directional indicators with a selectable relief.

Definition 

<arrow tag_attr="value"...>
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
</arrow>

Tag Attributes

Writable GTK3 GtkArrow, GtkMisc and GtkWidget properties can be used as tag attributes. The most useful properties are:

NameDescriptionValuesDefaultSince
arrow-typeDirection of the indicatorup, down, left, rightright 0.9.0
shadow-typeRelief around the indicatornone, in, out, etched-in, etched-outnone 0.9.0
xalign, yalignPosition within the allocated area0 to 10.5 0.9.0
xpad, ypadHorizontal and vertical paddingNon-negative pixels0 0.9.0

Directives

NameDescriptionContentsSince
variableName used to target the widget with functions; its exported value is emptyShell variable name 0.9.0
variable export="false"Variable name not exported to the shellShell variable name 0.9.0
sensitiveSensitive statetrue or false 0.9.0
action signal="type"Execute a command or function for a GTK signalActivity 0.9.0

Signals and Functions

There is no default signal for this widget. General GtkWidget signals can be named explicitly in an action.

The enable, disable, show, hide and grabfocus functions are supported.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<hbox spacing="8">
	<arrow arrow-type="up" shadow-type="in"></arrow>
	<arrow arrow-type="down" shadow-type="out"></arrow>
	<arrow arrow-type="left" shadow-type="etched-in"></arrow>
	<arrow arrow-type="right" shadow-type="none"></arrow>
</hbox>

GTK3 Note

GtkArrow is deprecated in GTK3 but remains available in GTK 3.24. The GTK3 port uses it directly because that preserves the established XML properties and appearance without a compatibility emulation.
