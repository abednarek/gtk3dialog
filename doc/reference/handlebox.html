handlebox widget

A static GTK3 single-child container retaining the historical <handlebox> XML name. GTK3 removed GtkHandleBox, so its detachable floating-window behaviour is unavailable.

Definition 

<handlebox tag_attr="value"...>
	widget
	<variable>varname</variable>
	<width>width-request</width>
	<height>height-request</height>
	<action signal="type">command</action>
</handlebox>

Exactly one direct child is required. A toolbar is a common child, but any GTK3 widget suitable for a single-child container may be used.

Tag Attributes

Writable scalar properties of the GTK3 box and its ancestors can be used as tag attributes. The first three legacy attributes below are accepted but have no effect; the common packing attributes still apply:

NameDescriptionValuesSince
handle-positionLegacy drag handle placement; ignored in GTK3left, right, top, bottom, or numeric enum value 0.9.0
snap-edgeLegacy floating-window snapping; ignored in GTK3left, right, top, bottom, or numeric enum value 0.9.0
shadow-typeLegacy frame style; ignored in GTK3GtkShadowType enum nickname or numeric value 0.9.0
space-expandPack widget expanding into spacetrue or false 0.9.0
space-fillPack widget filling spacetrue or false 0.9.0

Directives

The optional variable directive names the handle box for common functions and exports an empty value. The width and height directives set its size request. This container has no type-specific input, output, refresh, save, clear or movement functions.

Signals

This widget has no default signal. The former child-detached and child-attached events never occur in the static GTK3 backend. Common GtkWidget signals remain available.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. Visibility and sensitivity functions target the named handle box.

Example 

<handlebox>
	<toolbar>
		<toolbutton stock-id="gtk-new"><label>New</label></toolbutton>
		<toolbutton stock-id="gtk-open"><label>Open</label></toolbutton>
	</toolbar>
	<variable>TOOLBAR_HANDLE</variable>
</handlebox>

Notes

The child remains attached. Use a separate window if a detachable tool area is required; the GTK2 handle and snapping behaviour cannot be reproduced with a GTK3 container.

This widget was introduced in version 0.9.0.
