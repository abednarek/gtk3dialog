listbox widget

The GTK3-only GtkListBox presents arbitrary direct child widgets as vertically arranged rows. Each child keeps its own variable and actions. Unlike the older list tag, rows may contain complete widget layouts rather than just text items.

Definition 

<listbox names="first|second" selection-mode="single">
    <text><label>First row</label></text>
    <text><label>Second row</label></text>
    <variable>CHOICE</variable>
</listbox>

Every direct child is wrapped in a GtkListBoxRow. names supplies one nonempty, unique value per row; without it, zero-based row numbers are used. The selected name is the container's value.

Tag Attributes

NameDescriptionValuesSince
namesStable names in direct-child orderPipe-separated unique names 0.9.1
selection-modeRow selectionsingle (default) or none 0.9.1
activate-on-single-clickActivate a row on its first clickBoolean; GTK3 default when omitted 0.9.1

Common sizing, visibility, sensitivity, CSS, variable, action, default, input and output directives follow the common widget contract. The widget needs at least one direct child.

Value and Actions

The selected row name may be set with <default>, <input> or refresh, exported through a variable and saved through <output file>. Clear removes the selection. An unknown name leaves the current selection unchanged and produces a warning. selection-changed actions run synchronously after a row is selected or the selection is cleared. row-activated actions run when GTK activates a row. On a click that does both, selection actions precede activation actions. Direct child actions remain independent. Multi-selection is not supported because the GTKDialog value contract is scalar; use tree or iconview for multi-select data. removeselected is not supported for static XML child widgets; it does not silently destroy their variables or actions.

Example 

<window><vbox>
    <listbox names="summary|details">
        <text><label>Summary</label></text>
        <text><label>Details</label></text>
        <variable>ROW</variable>
        <action>echo "Selected: $ROW"</action>
        <action signal="row-activated">echo "Activated: $ROW"</action>
    </listbox>
</vbox></window>
