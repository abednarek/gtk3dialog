# GTKDialog showcase gallery

These screenshots cover every page of `examples/showcase/showcase`. Interactive
views show a combo cell in edit mode, an open row-aware popup menu, a running
VTE 2.91 terminal, a mixed dynamic notebook, a JSON-fed menu and an XEmbed
client attached to the generic GTK3 socket.

**Style:**
[`Greymond-Concrete`](https://github.com/parhelion22/xfce-theme-greymond),
`Sans 8`.
